# Examples

This folder contains integration examples for the PY32 EventRecorder port.

## GPIO_Toggle

`GPIO_Toggle` demonstrates a basic PY32 firmware project layout with EventRecorder sources/headers added to a Keil/IAR style project structure.

> Note: this example is currently kept as a reference snapshot and is not yet finalized as a polished, ready-to-ship demo.

Use it as a starting point for:

- include/source placement,
- project file wiring,
- and initial EventRecorder integration patterns.
